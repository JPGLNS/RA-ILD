# Step 05.3 single outer-fold modeling trial

## Purpose

This script tests one complete leakage-controlled outer task before expanding
the workflow to all 100 outer tasks.

Default task:

```text
outer_repeat = 1
outer_fold = 1
```

It runs four models using the same inner and outer splits:

```text
M0_clinical
M1_static_tcr
M2_static_tcr_public
M3_static_tcr_public_material
```

## Critical preflight validation

Before modeling, the script rebuilds the public sets from all 123 training
samples and requires exact agreement with step 03:

```text
global public: 394,235
RA-specific:    41,649
ILD-specific:   28,947
shared:         38,585
```

A mismatch stops execution. This confirms that the dynamic reference builder
uses the same biological definition as step 03.

## Default dynamic public predictors

The main `raw_bilateral` variant uses eight predictors:

```text
all_ref_public_clone_ratio
all_ref_public_frequency_sum

shared_ref_clone_ratio
shared_ref_frequency_sum

RA_specific_ref_clone_ratio
RA_specific_ref_frequency_sum

ILD_specific_ref_clone_ratio
ILD_specific_ref_frequency_sum
```

Raw clone counts are excluded because they are more depth-sensitive.
Set coverage, delta and log-ratio are retained in audit outputs but are not
simultaneously entered in this default model.

## Leakage control

For every inner fold:

```text
inner-training samples:
    public features generated by an extra stratified cross-fitting layer

inner-validation samples:
    reference built from inner-training samples only
```

For the final selected outer model:

```text
outer-training samples:
    cross-fitted public features without self-inclusion

outer-validation samples:
    reference built from all outer-training samples only
```

Encoding, zero-variance filtering and standardization are also learned from
the corresponding training partition only.

## Interpretation

This is an implementation/QC trial for one outer fold. Its AUC is not the
final model performance and must not be used to select the final model. After
the outputs pass review, the workflow can be expanded to all 100 outer tasks.

## Version 1.0.1 correction

`shared_ref` now exactly matches step 03:

```text
RA_group_public AND ILD_group_public
AND NOT RA_specific
AND NOT ILD_specific
```

The original 1.0.0 trial script omitted the final two exclusions and therefore
over-counted the shared set. The sparse cache itself is unaffected and can be reused.
